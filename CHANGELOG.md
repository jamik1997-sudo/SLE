# SLE v6.6.7

- Исправлен запуск обновления backend из админки.
- Systemd-сервис теперь запускается с `--no-block`: HTTP endpoint сразу
  возвращает управление, а обновление продолжается отдельно.
- Обновлено ограниченное sudo-правило для точной неблокирующей команды.
- Кнопка остаётся доступна только администратору и не принимает произвольные
  серверные команды.

В следующих обновлениях этот файл заменяется описанием только последней версии.
