# SLE v6.6.6

- В админке добавлена кнопка «Обновить backend».
- Запуск доступен только администратору через защищённый POST endpoint.
- Endpoint не принимает команды и может запустить только
  `sle-update.service`.
- Обновление выполняется в отдельном systemd-сервисе и не прерывается при
  перезапуске Uvicorn.
- Интерфейс ждёт восстановления `/health` и сообщает о завершении.
- Сохранены исправления проверки базы и расчёта пула.

В следующих обновлениях этот файл заменяется описанием только последней версии.
