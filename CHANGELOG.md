# SLE v6.5.8

- Мастер / Уверенный / Базовый загружают полный список завершённых визитов через backend.
- Убрана колонка «Завершён» из drill-down таблицы.
- Добавлены: Дата, Время, Сотрудник, Визит, Код ТТ, Регион, Оценивающий, Статус, Результат.
- «Завершённые визиты» на дашборде кликабельны и показывают все завершённые визиты по текущим фильтрам.
- Результат в списке рассчитывается отдельно для каждого визита.
- При выборе сотрудника среди руководителей остаётся только его закреплённый руководитель.
- Аудиторы и менеджеры остаются доступными.
- Строка визита открывает заполненный опросник конкретной точки.
