# SLE v6.6.4

- Backend рассчитывает полную ёмкость пула БД, процент использования и
  фактический признак высокой нагрузки.
- Отрицательное текущее значение SQLAlchemy `overflow()` больше не
  интерпретируется как уменьшение ёмкости пула.
- Frontend использует готовый признак `high_load` от backend и сохраняет
  совместимый fallback для старого API.
- Статус показывает активные соединения из полной ёмкости, базовый пул и
  доступный резерв.
- Версия кеша frontend повышена до 6.6.4.

В следующих обновлениях этот файл заменяется описанием только последней версии.
