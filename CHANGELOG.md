# SLE v6.5.9

- «Завершённые визиты» на дашборде теперь гарантированно кликабельны.
- Мастер / Уверенный / Базовый используют тот же drill-down.
- Drill-down снова показывает одну строку на завершённый аудит, а не отдельные точки.
- Колонки: Дата, Сотрудник, Регион, Оценивающий, Статус, Результат.
- Результат — итоговый процент всего аудита.
- Убраны Визит / Код ТТ / время / отдельный результат точки из этого списка.
- Сохраняется строгая фильтрация выбранного сотрудника по его руководителю.
