# SLE v6.0 — стабильная производительная версия

## Интерфейс
- Фильтры дашборда больше не отправляют запрос при каждом выборе.
- Регион мгновенно скрывает руководителей и сотрудников других регионов.
- Несовместимые значения сбрасываются локально.
- Один запрос отправляется только по кнопке «Применить».
- «Сбросить фильтры» очищает значения и выполняет один запрос.
- Предыдущий запрос отменяется, поэтому старый ответ не перерисует страницу.

## Backend
- При повторной фильтрации backend не формирует и не отправляет справочники фильтров.
- Справочники загружаются один раз и кешируются на клиенте и сервере.
- Добавлены составные PostgreSQL-индексы для дашборда, визитов и региональных выборок.
- Включены GZip, TTL-кеш и один Uvicorn worker для Oracle 1 GB RAM.

## Обновление
```bash
cd ~/SLE
git pull
cd backend
source venv/bin/activate
pip install -r requirements.txt
python run_migrations.py
sudo systemctl restart sle
```
После деплоя frontend очистите старый Service Worker один раз.
