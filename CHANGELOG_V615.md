# SLE v6.1.6 — защита от повторного создания аудита

- Кнопка «Начать» блокируется сразу после первого нажатия.
- Форма создания аудита принимает только одну отправку одновременно.
- Кнопки «Создать аудит» и «Назад» блокируются до завершения запроса.
- Backend использует PostgreSQL advisory lock для защиты от параллельных POST-запросов.
- Если активный аудит этого сотрудника уже создан тем же оценивающим сегодня, возвращается его ID вместо создания дубликата.
- PWA-кеш обновлён до 6.1.6.
