# SLE v6.1.8 — Stable Sync / Cloudflare

- Автосохранение опросника выполняется строго одной очередью: параллельные PUT `/sync` исключены.
- Изменения во время активного сохранения объединяются и отправляются следующим одним запросом.
- Комментарии и поля визита используют debounce 1200 мс; ответы 650 мс.
- При отсутствии сети данные остаются в локальном черновике и автоматически досохраняются после восстановления подключения.
- Для POST/PUT увеличен разумный таймаут до 15–18 секунд без повторной отправки мутаций.
- Cloudflare Worker корректно обрабатывает OPTIONS/CORS и возвращает CORS-заголовки даже при ошибке origin.
- Worker динамически разрешает запрошенные preflight-заголовки и поддерживает X-Device-ID.
- PWA/cache-busting обновлены до v6.1.8.
