# SLE v6.4.2 — Visit Comparison

New separate section: **Сравнение визитов**.

Access:
- Admin
- Manager
- Auditor
- Leader does not see or access the section.

Features:
- Filter by region and TT code.
- Optional date range.
- Full visit history for the selected TT.
- Per-visit point result and delta vs previous visit.
- Choose exactly two visits for detailed comparison.
- Summary: before/after/delta, improved, worsened, unchanged, unresolved 0→0.
- Block-by-block comparison.
- Question-by-question comparison with both visit comments.
- “Only changes” mode.
- N/A is displayed and not treated as score improvement/worsening.
- Existing Cloudflare Worker → DuckDNS → Oracle architecture is preserved.
