# SLE v6.5.5

1. Карточки Мастер / Уверенный / Базовый стали кликабельными.
   Открывается отдельный список всех завершённых аудитов по текущим фильтрам:
   Завершён, Дата, Сотрудник, Регион, Оценивающий, Статус, Результат.
2. Фильтр Сотрудник на дашборде применяется сразу и передаёт employee_id в backend.
   При выборе руководителя список сотрудников ограничивается его сотрудниками.
3. Статус сайта виден и вызывается только для Admin.
   Backend endpoint /extras/system-status также защищён ролью Admin.
