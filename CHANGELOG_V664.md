# SLE v6.6.4

## Исправление статуса пула БД

- Backend теперь рассчитывает полную ёмкость пула, процент использования и
  признак высокой нагрузки.
- Текущее отрицательное значение SQLAlchemy overflow() больше не
  интерпретируется как уменьшение ёмкости пула.
- Frontend использует готовый признак high_load от backend и сохраняет
  совместимый fallback для старого API.
- Статус показывает активные соединения из полной ёмкости, размер базового
  пула и доступный резерв.
- Версия кеша повышена до 6.6.4.
