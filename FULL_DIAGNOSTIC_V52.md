# SLE v5.2 — полная диагностика и исправления

- Отмена устаревших запросов dashboard через AbortController.
- Устранение визуальной перезагрузки и гонки старого/нового фильтра.
- Фильтр «Регион → Оценивающий»: руководители только выбранного региона; аудиторы и менеджеры доступны во всех регионах; администраторы не показываются.
- После ответа backend список фильтров обновляется без перезагрузки страницы.
- Список аудитов использует joinedload для скалярных связей и требует меньше SQL round-trip.
- Убрана принудительная перезагрузка dashboard-кеша при каждом применении фильтра.
- Версия PWA-кеша обновлена до 5.2.0.
