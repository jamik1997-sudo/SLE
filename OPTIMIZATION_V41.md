# SLE v4.1 Performance

Изменения без изменения дизайна:

- dashboard больше не загружает все ответы и визиты всех завершённых аудитов;
- общая статистика строится по компактным строкам аудитов;
- показатели блоков считаются агрегирующим SQL-запросом;
- полные answers/visits загружаются только для 10 последних аудитов;
- варианты фильтров кешируются 5 минут;
- dashboard кешируется 60 секунд;
- admin/bootstrap кешируется 60 секунд;
- добавлены составные PostgreSQL-индексы для dashboard, фильтров и списков;
- версия PWA-кеша обновлена до 4.1.0.

После обновления обязательно выполнить `python run_migrations.py`.
