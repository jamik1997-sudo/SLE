# SLE Audit v2 — расширенная версия без npm

Реализовано: дашборд, карточки сотрудников, глобальный поиск, журнал действий, аналитика и рейтинги, CSV и печать/PDF, QR-сканер кода ТТ, автоматический учёт времени визита, несколько черновиков, PWA и офлайн-очередь, светлая/тёмная тема, переключатель RU/UZ, конструктор вопросов и уровней оценки, удаление сотрудников. GPS полностью исключён.

Развёртывание: frontend — Vercel (Framework Other, Root frontend, без build/install command), backend — Render, база — Supabase PostgreSQL. После обновления очистить Service Worker и данные сайта. Новые таблицы создаются автоматически при старте backend.


## Новое в версии 2.1
- отчёт по заполнениям опросника и выгрузка всех ответов в CSV;
- самостоятельная смена пароля для всех ролей;
- отмена незавершённого аудита с сохранением записи в истории и журнале действий.
