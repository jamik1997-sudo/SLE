# SLE Audit v2 — расширенная версия без npm

Реализовано: дашборд, карточки сотрудников, глобальный поиск, журнал действий, аналитика и рейтинги, CSV и печать/PDF, QR-сканер кода ТТ, автоматический учёт времени визита, несколько черновиков, PWA и офлайн-очередь, светлая/тёмная тема, переключатель RU/UZ, конструктор вопросов и уровней оценки, удаление сотрудников. Автоматическое определение GPS исключено; координаты ТТ при необходимости вводятся вручную и попадают в Excel-отчёт.

Развёртывание: frontend — Vercel (Framework Other, Root frontend, без build/install command), backend — Render, база — Supabase PostgreSQL. После обновления ручная очистка Service Worker не требуется: версия обновляется автоматически. Новые таблицы создаются автоматически при старте backend.


## Новое в версии 2.1
- отчёт по заполнениям опросника и выгрузка всех ответов в CSV;
- самостоятельная смена пароля для всех ролей;
- отмена незавершённого аудита с сохранением записи в истории и журнале действий.

## Новое в версии 2.2 — автоматическое обновление PWA
- больше не требуется вручную очищать Service Worker и данные сайта после каждого релиза;
- `sw.js`, `app.js`, `styles.css`, `config.js` и HTML проверяются на обновления через сеть;
- новая версия Service Worker активируется сразу через `skipWaiting()` и `clients.claim()`;
- открытая страница автоматически перезагружается после активации новой версии;
- проверка обновлений выполняется при запуске, возврате на вкладку, фокусе окна и каждые 15 минут;
- старые версии кэша удаляются автоматически;
- офлайн-режим продолжает использовать последнюю успешно загруженную версию интерфейса.


## v2.3
- Все отчёты выгружаются в формате Excel (.xlsx).
- Выгрузка аудитов содержит отдельный лист со списком проверок.
- Отчёт по опроснику содержит листы «Заполнения» и «Сводка».

## v2.4
- В дашборд добавлены фильтры по региону, руководителю/менеджеру, сотруднику и месяцу.
- Фильтры применяются одновременно и учитывают права роли: руководитель видит только свой регион.
- В карточку визита добавлены название торговой точки и необязательные координаты, вводимые вручную.
- Excel-отчёты дополнены названием ТТ, кодом ТТ, координатами и ссылкой на карту.
- В отчёте аудитов добавлен отдельный лист «Торговые точки».
- Старый PWA-кэш обновляется автоматически до версии v2.4.
