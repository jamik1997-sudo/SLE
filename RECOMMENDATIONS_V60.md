# Рекомендации для Oracle 1 OCPU / 1 GB RAM

- Используйте один Uvicorn worker.
- Оставьте swap 2 GB.
- Не запускайте Docker, Redis и базу данных на этой VM.
- Supabase должен оставаться отдельной базой.
- Не загружайте на страницы 500 записей автоматически; используйте «Показать ещё».
- Перед каждым обновлением проверяйте `sudo journalctl -u sle -n 100 --no-pager`.
- Раз в неделю выполняйте `sudo apt update`; автоматический полный upgrade лучше делать в окно обслуживания.
- Render отключайте только после нескольких дней стабильной работы Oracle.
